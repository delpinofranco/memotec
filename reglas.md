# Memotec

## Reglas del juego

**Memotec** es un juego de memoria para **dos jugadores**, cuyo objetivo es encontrar la mayor cantidad posible de pares de imágenes iguales.

### Jugadores

El juego se juega entre **dos jugadores**:

* Jugador 1
* Jugador 2

### Inicio del juego

La partida comienza con el **Jugador 1**, quien debe apretar **El boton comenzar**, este solo se puede apretar una vez. El juego mostrara las cartas por 2 segundo. Luego las voltera. A partir de aquí el **Jugador 1** seleccionara dos imágenes para intentar encontrar un par.

### Turnos

* Si el jugador encuentra un **par de imágenes iguales**, obtiene un punto y **puede continuar jugando**.
* Si las dos imágenes seleccionadas **no forman un par**, el turno pasa al otro jugador. El cambio de turno se mostrara con un cambio de color en cartel donde figura  **jugador1**, **jugador2**
* Las mismas reglas se aplican para ambos jugadores durante toda la partida.

### Tiempo de juego

El juego **no tiene límite de tiempo**. Los jugadores pueden tomarse el tiempo que necesiten para recordar la ubicación de las imágenes y encontrar los pares.


### Boton reiniciar

En medio de una partida comenzada, cualquier usuario puede apretar este boton, comenzara todo de nuevo y se habilitara el boton comenzar.

### Finalización de la partida

La partida finaliza cuando se han encontrado **todos los pares de imágenes** disponibles en el tablero. El buscador mostrara un cartel con el resultado. El usuario hace click en aceptar y el tablero se auto completa.

### Ganador

El ganador es el jugador que haya encontrado **la mayor cantidad de pares de imágenes** al finalizar la partida.

En caso de que ambos jugadores encuentren la misma cantidad de pares, la partida termina en **empate**.
